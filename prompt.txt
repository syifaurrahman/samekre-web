# PROJECT: NATURAL ACEH 

## 1. ROLE & OBJECTIVE

Act as a Senior Frontend Engineer, UI/UX Designer, and Web Architect.

Build a complete, modern, professional, responsive website for **Natural Aceh**, using the existing React + Vite project.

Official reference website:
https://naturalaceh.org/

Your task is to study the reference website, understand its identity, content, navigation, programs, and organizational structure, then rebuild it with a significantly improved user interface and user experience.

This is a website reconstruction and modernization project, NOT a completely different website.

Preserve the original organization's identity, purpose, important information, and core content while improving the overall visual quality, usability, accessibility, and code architecture.

## 2. DESIGN DIRECTION

Design style: **Modern Minimalism / Nature-Inspired Editorial / Professional Institutional Website.**

The website should look elegant, clean, modern, trustworthy, and professional.

### Visual Guidelines

- Minimalist and clean layout.
- Generous whitespace and balanced spacing.
- Strong visual hierarchy.
- Consistent typography and color system.
- Elegant image presentation.
- Well-organized content sections.
- Subtle transitions and micro-interactions.
- Professional editorial-style layouts.
- Responsive design across all screen sizes.

### Color Palette

Use a nature-inspired color palette:

- Primary: Deep Forest Green (#173F35)
- Secondary: Natural Green (#527A62)
- Accent: Sage Green (#A8B9A0)
- Background: Warm Off-White (#F8F8F4)
- Surface: White (#FFFFFF)
- Text Primary: Charcoal (#242A26)
- Text Secondary: Muted Gray (#737B75)

Use colors consistently. Avoid excessive gradients, oversaturated colors, and unnecessary decorative elements.

### Typography

Use modern, highly readable typography.

Suggested fonts:
- Inter
- Manrope
- Plus Jakarta Sans

Use appropriate font weights, line heights, and heading sizes.

Headings should feel sophisticated and distinctive without being oversized.

## 3. ANIMATION & INTERACTION

Implement subtle, smooth animations throughout the website.

Use:
- Smooth hover transitions.
- Gentle fade-in animations when sections enter the viewport.
- Subtle image zoom on hover.
- Smooth dropdown navigation.
- Elegant button hover effects.
- Small movement transitions for interactive elements.
- Smooth mobile navigation transitions.

Animation requirements:
- Duration approximately 200–400ms.
- Use natural easing curves.
- Avoid excessive motion.
- No distracting bouncing effects.
- No unnecessary parallax.
- No excessive animated backgrounds.
- Respect prefers-reduced-motion.

The overall experience should feel premium, lightweight, and natural.

## 7. RESPONSIVE DESIGN

The website must work properly on:

- Desktop (1440px and above).
- Laptop (1024px–1366px).
- Tablet (768px–1023px).
- Mobile (320px–767px).

Requirements:
- Responsive navigation.
- Responsive typography.
- Flexible grid systems.
- Proper image scaling.
- No horizontal overflow.
- Appropriate spacing on mobile.
- Touch-friendly interactive elements.
- Consistent visual hierarchy on every screen size.

Mobile design should be intentionally designed, not simply a compressed desktop layout.

## 8. FUNCTIONAL REQUIREMENTS

All visible interactive elements must work.

Implement:
- Functional navigation.
- Dropdown menus.
- Mobile navigation menu.
- Search interface.
- Article and project navigation.
- Category filtering where appropriate.
- Contact form validation.
- Social media links.
- Back-to-top functionality.
- Appropriate loading and empty states.

Use React Router for page navigation.

If an external service or backend is unavailable, implement a sensible frontend solution and clearly indicate where backend integration is required.

Do not create fake successful form submissions.

## 11. STRICT DESIGN RULES

The final website must NOT look like:
- A generic AI-generated website.
- A standard Bootstrap template.
- An overcrowded WordPress theme.
- A dashboard disguised as a landing page.
- A website with excessive gradients and glassmorphism.
- A website full of unnecessary floating elements.
- A website with excessive animation.

Avoid overdesign.

Prioritize excellent typography, whitespace, grid alignment, photography, and consistency.

Every section should have a clear purpose.

## 12. EXECUTION WORKFLOW

Work in the following order:

**Phase 1 – Reference Analysis**
- Inspect the official Natural Aceh website.
- Study its homepage, navigation, program pages, articles, publications, and contact information.
- Identify its existing visual identity and content hierarchy.
- Identify unavailable or broken pages.
- Do not reproduce irrelevant external links, injected content, or suspicious scripts.

**Phase 2 – Planning**
- Establish design tokens.
- Define typography and color systems.
- Create reusable components.
- Define page routes and content structure.

**Phase 3 – Development**
- Build the shared layout.
- Implement the header and navigation.
- Build the homepage.
- Implement internal pages.
- Add responsive styling.
- Add subtle animations and interactions.

**Phase 4 – Quality Assurance**
- Run the development server.
- Test every page.
- Test navigation and interactive components.
- Inspect mobile, tablet, and desktop layouts.
- Fix broken images.
- Fix layout issues and console errors.
- Verify that the project builds successfully.

**Phase 5 – Final Polish**
- Review the overall visual consistency.
- Improve spacing and typography.
- Refine hover states and transitions.
- Remove unused code and unnecessary dependencies.
- Ensure the finished website feels like a professionally designed institutional website.

## 13. IMPORTANT FINAL INSTRUCTIONS

Do not stop after creating the homepage.

Build a cohesive multi-page website with a reusable component architecture.

Do not simply provide suggestions, mockups, or explanations. Actually implement the website in the existing React + Vite project.

Make reasonable technical and design decisions independently.

Do not ask unnecessary questions.

When the reference website contains inaccessible pages, preserve the relevant navigation structure where useful, but do not fabricate the missing content. Use a graceful fallback or clearly marked placeholder until verified content is available.

The final result should be a polished, professional, modern, minimalist, responsive Natural Aceh website that maintains its original organizational identity while significantly improving its digital presence.

**Design priority: Minimalism, readability, functionality, responsiveness, consistency, and subtle elegance.**
